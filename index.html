Telegram Gifts Bot

This application is a 100% backend Telegram Bot written in Node.js LTS (CommonJS) with SQLite and Telegraf.

  • Main Entry: index.js (run via npm start or PM2)
  • Telegram Stars Payments: Currency XTR with atomic ledger transactions
  • Official Gifts: getAvailableGifts, sendGift & claim deep links
  • Languages: Uzbek (uz) & Russian (ru)
  • Admin Panel: In-Telegram via /admin
  • Automated Tests: Run npm test

Set your BOT_TOKEN in .env and connect via Telegram.
